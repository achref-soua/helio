# Support

Thanks for using Helio! Here is where to go for help.

## Questions & discussion

- **How do I…? / Is this possible?** Open a thread in
  [**GitHub Discussions**](https://github.com/achref-soua/helio/discussions) —
  the best place for usage questions, ideas, and show-and-tell.
- **Documentation:** start with the [README](./README.md) and the docs site in
  [`apps/docs`](./apps/docs) (concepts, self-hosting, configuration, and a guide
  for every feature). The
  [configuration reference](./apps/docs/content/docs/configuration.mdx) covers
  every environment variable, and the REST API is specified by the OpenAPI
  document served by the gateway at `/openapi.json`.

## Bugs & feature requests

- **Found a bug?** Open an [issue](https://github.com/achref-soua/helio/issues/new/choose)
  using the **Bug report** template (include the version, your deployment, and a
  reproduction).
- **Have an idea?** Use the **Feature request** template.

## Security

Please do **not** report security vulnerabilities in public issues. Follow
[`SECURITY.md`](./SECURITY.md) — use GitHub
[private vulnerability reporting](https://github.com/achref-soua/helio/security/advisories/new),
or email the address listed there.

## Contributing

See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the development setup, the branch
and commit conventions, and the quality gate every PR must pass.
